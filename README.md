# ИИ-помощник для абитуриентов МГТУ

Чат-бот приёмной комиссии, который отвечает на вопросы абитуриентов, используя правила приёма и архив статистических данных.

## О проекте

Проект реализуется в рамках программы «Сириус.Лето» на базе МГТУ. 
Цель — создать умного помощника, который помогает абитуриентам быстро получать ответы на вопросы о поступлении.

## Технологии

- Python 3.9+
- Git (система контроля версий)
- [Библиотеки будут добавлены по мере разработки: Aiogram / TeleBot, Pandas, PyPDF2 и др.]
